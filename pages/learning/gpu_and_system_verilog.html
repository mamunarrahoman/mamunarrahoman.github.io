COURSE TITLE: GPU Design in SystemVerilog

Platform: SEMIRISE

Introduction: A GPU is essentially a processor designed to execute many similar operations in parallel. A CPU typically has a relatively small number of powerful cores, whereas a GPU contains a large number of smaller execution units. The key idea behind a GPU is the combination of a large amount of arithmetic hardware and a mechanism for keeping those hardware units busy by efficiently distributing parallel workloads.

Feature CPU GPU
Core count Few, powerful cores Many, smaller execution units
Optimized for Low-latency, sequential work High-throughput, parallel work
Control logic Complex (branch prediction, out-of-order execution) Simple, shared across groups of units
Silicon area Large share for cache and control Large share for arithmetic units
Typical workload OS, general-purpose programs Graphics, matrix math, ML

Note: Latency is the time delay for a single request to travel from start to finish, while throughput is the total volume of work or data processed over a given period
