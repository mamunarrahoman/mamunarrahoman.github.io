--- RISC-V ---

Introduction: RISC-V is a free and open standard instruction set architecture (ISA) for computer CPUs. It is based on reduced instruction set computer (RISC) principles. Unlike proprietary ISAs such as x86 and ARM, RISC-V is described as "free and open" because its specifications are released under permissive open-source licenses and can be implemented without paying royalties. - [wikipedia]
RISC-V is a popular architecture for microcontrollers and embedded systems, with development of higher-performance implementations targeting mobile, desktop, and server markets ongoing. The ISA is supported by several major Linux distributions, and companies such as SiFive, Andes Technology, SpacemiT, Synopsys, Alibaba (DAMO Academy), StarFive, Espressif Systems, and Raspberry Pi offer commercial systems on a chip (SoCs) and microcontrollers (MCUs) that incorporate one or more RISC-V compatible processor cores. - [wikipedia]

RISC-V features:

  • High performance per watt for battery optimized devices.
  • Execute one action per instruction.
  • Supports more register and spends less time on loading and storing values to memory.
  • Reduced instruction set, simple decoding logic, less chip space is used, fewer transistor are required, and more general-purpose register can fit into the central processing unit.

Arithmatic and Logic instructions:

Instructions Arguments Comment Description
add rd, rs1, rs2 # rd = rs1 + rs2 Adds the values of rs1 and rs2 and stores the result in rd.
sub rd, rs1, rs2 # rd = rs1 - rs2 Subtracts the value of rs2 from rs1 and stores the result in rd.
and rd, rs1, rs2 # rd = rs1 & rs2 Performs a bitwise AND operation on rs1 and rs2 and stores the result in rd.
or rd, rs1, rs2 # rd = rs1 | rs2 Performs a bitwise OR operation on rs1 and rs2 and stores the result in rd.
xor rd, rs1, rs2 # rd = rs1 ^ rs2 Performs a bitwise XOR (exclusive OR) operation on rs1 and rs2 and stores the result in rd.
s11 rd, rs1, rs2 # rd = rs1 << rs2 Performs a logical left shift on rs1 by the number of bit positions specified in rs2.
sr1 rd, rs1, rs2 # rd = rs1 >> rs2 Performs a logical right shift on rs1, filling the vacated upper bits with zeros.
sra rd, rs1, rs2 # rd = rs1 >>> rs2 Performs an arithmetic right shift on rs1, preserving its sign bit while shifting.
slt rd, rs1, rs2 # rd = (rs1 < rs2) ? 1:0 Compares rs1 and rs2 as signed integers and stores 1 in rd if rs1 is less than rs2; otherwise, stores 0.
sltu rd, rs1, rs2 # rd = (rs1 <u rs2) ? 1:0 Compares rs1 and rs2 as unsigned integers and stores 1 in rd if rs1 is less than rs2; otherwise, stores 0.

Note: No subtract immediate instruction in RISC-V
